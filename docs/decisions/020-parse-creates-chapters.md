# ADR 020：解析确认由 AI 划分卷/章

## 背景

确认解析曾把所有新场写入用户当前选中的卷/章。用户必须先手建章节，AI 不会自己分章。

## 决策

1. 每条提案场带 `volumeName` + `chapterName`。模型按情节分段；normalize 接受 `chapter` / `chapter_name` / `章` 等别名。
2. 若整份提案都没有章名且场次 ≥ 3，服务端按场序派生章节（约 2 场一章，章名取该组首场标题）。
3. 确认时按标题查找或创建卷/章。只有全部场落在同一章名、且请求带了 `volumeId`+`chapterId` 时，才写入该选中章（单章回退）。
4. 新项目可复用空的默认「Chapter 1」并改名。确认后删除仍为空的 Untitled scene。

## 后果

Story 树与大纲按 AI 分段呈现。用户仍可事后改章名、搬场、删章。
