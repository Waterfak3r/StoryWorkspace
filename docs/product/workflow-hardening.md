# 完善工作流

这是主代理**改进已通漫画主链**时的作业方式，不是新切片许可。实现范围仍以 [mvp.md](./mvp.md) 为准。

## 目标

漫画由工作流直出。图只证明链路，不代替链路。人不手改 JSON、不手改人设、不手改像素来「修这一张」。

## 一轮 = 一页

1. **摊开**这一页 Compiler / `resolveContext` 会吃到的：实体身份、`visual.spatial`、本场此刻状态、确认对白、分镜 action、页分组。
2. **对情节**：和本场原文比，标出对不上的洞（身份污染、状态挂错场、对白说话人/赋格、缺实体、镜序、源文本缺段）。
3. **和 agy 对链路**（Herdr）。agy 不改后端；后端洞由主代理判断后改。不要让它审画面美。每次只给这一页的证据；文字/生图 API 挂了就**新开 agy**（清上下文），不要把整本会话堆进去。
4. **改工作流**：schema / parse / 状态推断 / 对白 / 导演 / Compiler / 生图验收。改范围先改 `mvp.md`（必要时 ADR）。
5. **直出验收**：用改过的链生成**这一检验页**（或约定的下一页）。手改后再画不算过。1×1 / 过小 PNG 不是页。
6. **记下新洞**进下一轮。禁止一次出完全书再回头看。

## API 失败

- 文字 API 失败：重试有限次；仍失败则清上下文开 agy，只把本步输入（原文片段、场、实体名单）交给它产出 JSON，再走同一 Zod / confirm 入口。
- 生图 API 失败：重试有限次；**不得**把假 adapter / 1×1 标成 `success`。仍失败则停在这一页，记洞，开新 agy 审编译 prompt 与上游 JSON，不写假图充数。
- `startWorkflow` 不得把不可用的 `current/` 当「已出页」跳过。

## 禁止

- 以观感评图代替溯源
- 手改实体 / state / 分镜后再重画，当作工作流已修好
- **检查并改实体/状态 JSON 当完成。** 洞在 parse confirm、时间序、推断、对白赋格、Compiler、生图验收这些函数里修。人设只写首次稳定外观。
- 为修一张图绕过 parse → 身份 → 此刻状态 → 导演 → 对白 → compile
- 源文本缺段还继续往后画（先补全摄入，再出缺的场）

## 当前检验（《麦琪的礼物》）

| 页 / 场 | 情节此刻 | 过线标准 |
|---------|----------|----------|
| 源文本 | 全文 | 含 Mme. Sofronie / 卖发 / 买表链；金表是道具 |
| page-01-01 | 未剪发 | 长发；门牌不是对白 |
| 卖发场 | 店里剪发、二十元、找表链 | 单独一场；不得从「决心」跳到「回到家」 |
| page-02-01 | 已剪发、等待 | 短卷发来自场 2 此刻状态；「Please God」挂在等门那一格；不得补全未确认半句 |
| page-03-01 | Jim 进门，已剪发 | 真页图（不是 1×1）；短发仍在；先对质头发、再拆礼物 |
| page-03-02 | 表链与卖掉金表 | 真页图；对白挂在对的格上；关键句不得 `shotId: null` |

确认对白若因配额留下未赋格的关键句，一键开始要按节拍重挂，不得拿着残缺确认去生图。Compiler 里此刻 `condition` 盖过人设里同一方面（发长）。
